# Семейный архив

Локальный семейный архив без сервера: просмотр, редактирование, JSON-данные и папка с медиа.

## Скачать

Готовый ZIP-архив для использования: https://github.com/web3blind/family-archive/releases/latest/download/family-archive.zip

## Структура папки

```text
family-tree/
  index.html          # просмотр архива
  edit.html           # редактор архива
  archive.json        # данные семьи
  assets/             # стили и JavaScript
  media/              # фото, аудио, видео, документы
```

## Как открыть

Лучший вариант для проверки на компьютере:

```bash
python3 -m http.server 4177 --bind 127.0.0.1
```

Потом открыть в браузере:

- просмотр: `http://127.0.0.1:4177/index.html`
- редактор: `http://127.0.0.1:4177/edit.html`

`index.html` и `edit.html` также можно открыть как локальные файлы, но некоторые браузеры ограничивают загрузку `archive.json` при открытии через `file://`. Поэтому для надёжной работы лучше локальный статический сервер.

## Как редактировать архив

1. Откройте `edit.html`.
2. Добавьте людей, истории и медиа.
3. Укажите связи: мать, отец, связанные истории и медиа.
4. Нажимайте “Сохранить в браузере”, чтобы не потерять черновик текущей работы.
5. Когда изменения готовы, нажмите “Скачать archive.json”.
6. Замените старый `archive.json` в папке архива новым скачанным файлом.

Важно: браузер хранит черновик в `localStorage`, но постоянный переносимый источник данных — файл `archive.json`.

## Как добавить фото, аудио, видео или документ

Все медиа лежат в одной папке `media/`.

### В Chromium / Chrome

1. Откройте `edit.html`.
2. В разделе “Медиа” нажмите “Разрешить папку архива”.
3. Выберите папку, где лежат `index.html`, `edit.html`, `archive.json` и `media/`.
4. Создайте новую запись медиа.
5. Нажмите “Выбрать файл для media/”.
6. Редактор определит тип, поставит путь вида `media/file-name.ext` и скопирует файл в `media/`.
7. Свяжите медиа с человеком или историей.
8. Скачайте обновлённый `archive.json`.

### В браузерах без разрешения папки

1. Положите файл вручную в `media/`.
2. В `edit.html` создайте запись в разделе “Медиа”.
3. Укажите тип и относительный путь, например:
   - `media/grandmother.jpg`
   - `media/interview.mp3`
   - `media/family-meeting.mp4`
   - `media/letter.pdf`
4. Свяжите медиа с человеком или историей.
5. Скачайте обновлённый `archive.json`.

## Как смотреть результат

Откройте `index.html`.

В просмотре доступны:

- древо предков;
- краткие карточки людей;
- раскрытая полная карточка человека;
- истории;
- фото с полноразмерным lightbox;
- аудио и видео с встроенными controls;
- документы как ссылки на файлы.

## Как передать архив родственникам

Передайте всю папку целиком:

```text
index.html
edit.html
archive.json
assets/
media/
README.md
```

Можно скопировать папку на флешку, отправить ZIP-архивом или положить в облако.

## Проверки для разработки

```bash
node tests/archive-core.test.cjs
python3 tests/chro-smoke.py
python3 tests/chro-media-smoke.py
```
