# Семейный архив

Локальный семейный архив без сервера: просмотр, редактирование, JSON-данные и папка с медиа.

## Приложения desktop и Android (0.3.3)

Сборки Windows, Linux, macOS (Intel и Apple Silicon) и Android 0.3.3: https://github.com/web3blind/family-archive/releases/tag/v0.3.3

Скачайте один цельный ZIP для своей desktop-платформы и распакуйте его целиком. Android устанавливается из APK. Это тестовая версия: ограничения и выполненные проверки перечислены в `TESTING.md`.

- Desktop: Electron, Windows x64, Linux x64, macOS Intel x64 и Apple Silicon arm64.
- Android: Capacitor 7, package `xyz.blinddev.familyarchive`; сборка APK для тестирования подписана debug-ключом, не предназначена для публикации в магазине.
- Нет аккаунтов, обязательного облака или удалённого сервера. Node.js и Java нужны разработчику для сборки, а не пользователю готового приложения.

### Работа в приложении

1. Откройте редактор и добавьте человека. Сохраните карточку соответствующей кнопкой.
2. В карточке человека добавьте файлы или папку, выберите главное фото и сохраните карточку. Вложения можно также загрузить без привязки в общую библиотеку.
3. Добавляйте мать, отца и истории из карточки человека. Черновики сохраняются при переходах; для подтверждённой записи нажмите «Сохранить». Для создания человека достаточно имени.
4. Для передачи родственникам используйте «Экспортировать полный архив»: ZIP содержит `archive.json` и медиа. Старая схема JSON + папка `media/` сохраняется.
5. Desktop может открыть существующую папку архива или импортировать ZIP/JSON с файлами рядом. Android импортирует ZIP через системный выбор документа; JSON без медиа не переносит вложения.

**Изменение рабочего кода, пока не опубликовано:** desktop хранит рабочие данные приложения в `data/` рядом с исполняемым файлом Windows/Linux; на macOS — рядом с `.app`, вне подписанного bundle. При первом запуске создаются `archive/archive.json` (валидный пустой архив), `archive/media/`, идентификаторы архива, `selected-archive.json`, `imports/` и `session/` (Chromium/localStorage и черновики). В режиме разработки это `data/` в корне проекта; `FAMILY_ARCHIVE_DATA_DIR` задаёт отдельную тестовую папку без чтения старого пользовательского профиля.

Для переноса **закройте приложение и скопируйте всю папку приложения вместе с `data/`**; на macOS перенесите `.app` и соседнюю `data/` вместе. Открытие внешней папки копирует её в `data/imports/`, оригинал не редактируется; дальнейшая работа не зависит от внешнего пути. ZIP-экспорт содержит архив и медиа, но не черновики Chromium. Каталог должен быть доступен для записи: при ошибке нет скрытого сохранения в системном профиле.

Если `data/` ещё нет, старый Electron-профиль автоматически копируется без удаления оригинала: полная проверенная копия профиля и выбранного архива сохраняется в `data/legacy-backup/`, рабочая копия публикуется атомарно после проверки JSON, вложений и SHA-256 всех файлов. Закройте старую версию перед переносом. При повреждённом JSON, отсутствующем выбранном архиве/медиа или небезопасных ссылках запуск остановится с ошибкой, а не создаст пустую семью. Исправьте исходные файлы и повторите запуск. Существующая переносимая `data/` имеет приоритет и не перезаписывается старым профилем. После прерванного переноса незавершённая соседняя `data.stage-*` не используется как рабочий архив; исходные данные сохраняются.

Android остаётся отдельным режимом: копия находится внутри приложения, **удаление приложения удалит её**; регулярно экспортируйте ZIP во внешнее хранилище. Системный выбор облачного документа не гарантирует его доступность офлайн до завершения копирования. Браузерная версия не меняется.

Сохранение идёт на диск, а не в `localStorage`; ошибка записи показывается явно. Есть резервный JSON предыдущего сохранения, а импорт полной копии не должен уничтожать текущие данные при ошибке. Несохранённые поля форм защищены от незаметного сброса. Приложение не синхронизирует изменения между родственниками автоматически.

### Категории историй (рабочие исходники, ещё не выпущены)

У истории можно выбрать одну необязательную категорию: «Семейные истории», «Письма потомкам», «Семейные знания», «Место и дом», «Замыслы и итоги» или «Начало родовой книги». Старые истории остаются без категории; автоматической классификации нет. Чтобы убрать назначение, выберите «Без категории» и сохраните историю.

В разделе «Все истории» фильтр категории работает вместе с поиском по названию. Категория также показывается рядом с историей в редакторе карточки человека и в просмотре. Авторы, даты, тексты, связи и вложения остаются прежними. Категория переносится в JSON и полном ZIP; выбор фильтра — локальная настройка редактора, не часть семейного архива.

В просмотре, в разделе «Истории» полной карточки человека, категории выбираются флажками: можно отметить одну или несколько, включая «Без категории». Показаны истории любой из выбранных категорий. Если ничего не отмечено, видны все истории человека; кнопка «Показать все категории» снимает отметки. Выбор действует при переходах между людьми в текущем просмотре, а перезагрузка страницы возвращает все категории. Счётчик сообщает число показанных историй; архив и вложения фильтром не изменяются.

Формат остаётся schema v1, с необязательным полем `category` у истории. Старые версии открывают такой архив, но при пересохранении могут удалить категории, поэтому храните резервную копию и не редактируйте категоризированный архив в старой версии. Опубликованные сборки 0.3.3 эту возможность ещё не содержат.

### Переносимость и резервные копии

- JSON: до 16 МиБ; один файл: до 512 МиБ; JSON вместе со всеми медиа: до 1 ГиБ; ZIP: до 1000 записей (файлы/каталоги, включая JSON).
- Полный ZIP включает все безопасные файлы `media/`, даже если запись о вложении удалена. Удаление записи не удаляет сам файл.
- Вложенные пути с кириллицей сохраняются. Неподдерживаемые пути/форматы и отсутствующие вложения отклоняются до замены архива.
- Документы открываются системным приложением; возможность воспроизвести фото/аудио/видео зависит от поддержки конкретного формата устройством.
- Для Android-экспорта нужна свободная память для временной ZIP-копии. При ошибке внешнего хранилища рабочая копия остаётся в приложении; внешний неполный файл не считайте резервной копией.

### Сборка разработчиком

Требуется Node.js 22.12+:

```bash
npm ci
npm test
npm run desktop:start
npm run build:linux
npm run build:windows
npm run build:mac
```

Desktop-артефакты: `dist-desktop/family-archive-linux-x64.tar.gz`, `family-archive-win-x64.zip`, `family-archive-mac-x64.zip`, `family-archive-mac-arm64.zip`. Linux tar.gz распаковывается с сохранением исполняемых прав; запускайте `family-archive`. В Windows запускайте `Family Archive.exe`, на macOS — `.app` из соответствующего ZIP. Windows/macOS-сборки без коммерческой подписи; предупреждения SmartScreen/Gatekeeper возможны. Не отключайте защиту системы целиком.

Для Android требуются JDK 21, Android SDK с platform 35/build-tools 35.0.0 и корректные `JAVA_HOME`/`ANDROID_HOME`:

```bash
npm run android:sync
cd android
./gradlew :app:assembleDebug :app:testDebugUnitTest --no-daemon
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`. Частные ключи release-подписи не входят в проект.

### Проверки и ограничения

- Node: ядро, очереди native-сохранений, ошибки записи, пути, медиа и ZIP roundtrip.
- Electron Linux: реальное окно, человек и история, picker API с тестовым выбором, фото/аудио/документ, ZIP, импорт, отмена, перезапуск, несохранённые поля и блокировка второй копии.
- Общий корпус: 34 валидных/невалидных архива проверены JS и Java. Desktop → Android-хранилище → desktop сохраняет JSON и байты вложений.
- Android: Java unit-тесты, API lint, проверка подписи и компиляция APK. Системные диалоги, воспроизведение медиа и TalkBack требуют отдельной проверки на Android-устройстве.
- Windows/macOS: упаковка не означает проверку запуска на этих ОС. NVDA/TalkBack не считаются проверенными по DOM/unit-тестам.

## Скачать HTML-версию

Готовый ZIP-архив ранее опубликованной переносимой HTML-версии: https://github.com/web3blind/family-archive/releases/download/v0.1.0/family-archive.zip

## Структура папки

```text
family-tree/
  index.html          # просмотр архива
  edit.html           # редактор архива
  archive.json        # данные семьи
  assets/             # стили и JavaScript
  media/              # фото, аудио, видео, документы
```

## Как открыть

Лучший вариант для проверки на компьютере:

```bash
python3 -m http.server 4177 --bind 127.0.0.1
```

Потом открыть в браузере:

- просмотр: `http://127.0.0.1:4177/index.html`
- редактор: `http://127.0.0.1:4177/edit.html`

`index.html` и `edit.html` также можно открыть как локальные файлы, но некоторые браузеры ограничивают загрузку `archive.json` при открытии через `file://`. Поэтому для надёжной работы лучше локальный статический сервер.

## Как редактировать архив

1. Откройте `edit.html`.
2. Добавьте людей, истории и медиа.
3. Укажите связи: мать, отец, связанные истории и медиа.
4. Нажимайте “Сохранить в браузере”, чтобы не потерять черновик текущей работы.
5. Когда изменения готовы, нажмите “Скачать archive.json”.
6. Замените старый `archive.json` в папке архива новым скачанным файлом.

Важно: браузер хранит черновик в `localStorage`, но постоянный переносимый источник данных — файл `archive.json`.

## Как добавить фото, аудио, видео или документ

Все медиа лежат в одной папке `media/`.

### В Chromium / Chrome

1. Откройте `edit.html`.
2. В разделе “Медиа” нажмите “Разрешить папку архива”.
3. Выберите папку, где лежат `index.html`, `edit.html`, `archive.json` и `media/`.
4. Создайте новую запись медиа.
5. Нажмите “Выбрать файл для media/”.
6. Редактор определит тип, поставит путь вида `media/file-name.ext` и скопирует файл в `media/`.
7. Свяжите медиа с человеком или историей.
8. Скачайте обновлённый `archive.json`.

### В браузерах без разрешения папки

1. Положите файл вручную в `media/`.
2. В `edit.html` создайте запись в разделе “Медиа”.
3. Укажите тип и относительный путь, например:
   - `media/grandmother.jpg`
   - `media/interview.mp3`
   - `media/family-meeting.mp4`
   - `media/letter.pdf`
4. Свяжите медиа с человеком или историей.
5. Скачайте обновлённый `archive.json`.

## Как смотреть результат

Откройте `index.html`.

В просмотре доступны:

- древо предков;
- краткие карточки людей;
- раскрытая полная карточка человека;
- истории;
- фото с полноразмерным lightbox;
- аудио и видео с встроенными controls;
- документы как ссылки на файлы.

## Как передать архив родственникам

Передайте всю папку целиком:

```text
index.html
edit.html
archive.json
assets/
media/
README.md
```

Можно скопировать папку на флешку, отправить ZIP-архивом или положить в облако.
