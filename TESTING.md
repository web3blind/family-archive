# Проверка семейного архива 0.2.0

## Выполнено на Linux-сервере

- `npm test`: 19 тестов, 0 ошибок.
- `gradlew testDebugUnitTest lintDebug assembleDebug`: успешно. 16 unit-тестов (11 storage, 4 validation, 1 тест из официального шаблона), 0 ошибок. API lint без ошибок; предупреждения ресурсов/версий библиотек не скрывались.
- Общий корпус из 34 архивов проходит обе проверки — JavaScript и Java.
- Desktop ZIP → скомпилированное Android-хранилище → desktop ZIP: JSON двух людей, родительские связи, история, фото, аудио, документ и вложение без ссылки совпадают. Это проверка настоящего файлового кода, не Android-устройства.
- Исходное и упакованное Electron-приложение под Linux: создание человека и истории, выбор/копирование фото, аудио и документа, ZIP export/import, отмена замены, сохранение несохранённых полей, сохранение фокуса, загрузка изображения и WAV, показ ошибки открытия документа, восстановление после перезапуска. Диалоги выбора используют тестовые результаты; внешний просмотрщик заменён намеренной ошибкой для проверки сообщения.
- Реальный запуск двух упакованных desktop-процессов с одной папкой данных: второй не может записать поверх первого.
- ZIP/TAR проверены; 10 runtime-файлов в каждом из четырёх desktop-пакетов побайтово совпадают с текущими исходниками. Версия 0.2.0. Подтверждены PE x64, ELF x64, Mach-O x64 и arm64.
- APK содержит текущие web-файлы и пустой стартовый архив; подпись проверена `apksigner`. Package `xyz.blinddev.familyarchive`, версия 0.2.0, min SDK 23, target SDK 35. Частные ключи не входят в передачу.
- `npm audit` и `npm audit --omit=dev`: 0 vulnerabilities; обе проверки выполнены.
- `git diff --check`: без ошибок.

## Не проверено

- Запуск Windows/macOS на соответствующих ОС.
- Android-устройство/эмулятор: системный picker, внешний просмотрщик, перезапуск процесса и реальные media URL.
- NVDA, TalkBack и другие настоящие скринридеры.
- Магазины приложений, release-подпись, notarization, автоматическое обновление.

Сборки предназначены для проверки, не объявлены полностью проверенным production-релизом. Windows/macOS не имеют собственной издательской подписи. На macOS может потребоваться локальная пересборка/подпись; не отключайте защиту системы целиком.

## Проверка на устройстве

Используйте только тестовую семью. Добавьте человека, историю, фото, аудио и PDF; сохраните, перезапустите приложение, откройте медиа, экспортируйте ZIP и импортируйте обратно. При отмене выбора или ошибке импорта текущие данные должны оставаться прежними. Проверьте названия кнопок, фокус, сообщения об ошибках и системные диалоги настоящим скринридером.

На Android удаление приложения удаляет рабочую копию. Перед удалением/переустановкой экспортируйте ZIP вне приложения и проверьте его импорт. Нужен современный Android System WebView. Между родственниками нет автоматической синхронизации.

Сборки и исходники версии 0.2.0 публикуются в GitHub Releases: https://github.com/web3blind/family-archive/releases/tag/v0.2.0. Публикация не отменяет перечисленные ограничения проверки.
