# Проверка семейного архива 0.3.0

## Подтверждённые проверки

- `npm test`: 42 теста, 0 ошибок/пропусков. Шесть реальных Chromium-сценариев: создание человека только с именем, родители, циклы, общие вложения, главное фото, истории, браузерный импорт/экспорт, восстановление черновиков, ошибки записи, пакетный выбор и папки.
- Два разных файла с одинаковыми именами/размерами/датами сохраняют разные байты. В Chromium проверено копирование через реальные OPFS handles; системный выбор папки подменён.
- Native черновики привязаны к идентичности хранилища. Проверены запрет записи в чужой архив/после смены поколения, устаревшие черновики, повторная проверка перед восстановлением, возврат к исходному архиву.
- `xvfb-run -a node_modules/.bin/electron --no-sandbox tests/editor-electron.cjs`: реальный production preload и ArchiveStore, имя без обязательной биографии, родитель, batch folder partial failure, отказ записи/перезапуск/повтор, сравнение байтов файлов, главное фото, история, ZIP roundtrip и просмотрщик. Ошибки записи в выводе намеренно вызваны тестом.
- Исходное и упакованное Linux-приложение: integrated smoke и restart прошли; реальный main IPC, протокол, сохранение, родитель, фото, история, ZIP и перезапуск. Выбор файлов в smoke подставлен, а не проверен вручную.
- Android `testDebugUnitTest lintDebug assembleDebug`: успешно; 24 JVM-теста без ошибок. Lint-предупреждения библиотек/ресурсов не скрывались. Web-assets синхронизированы после окончательных исправлений.
- Native identity, storage limits, symlinks, exclusive file copies и отмены покрыты регрессиями. Старый portable schema v1 сохранён.
- Windows ZIP проверяется на целостность, длинные пути и отсутствие Android build-файлов. Runtime-файлы ASAR сверяются с исходниками; APK web-assets сверяются с исходниками. Android versionCode 2 / versionName 0.3.0.

## Границы подтверждения

- Реальные Windows/Android устройства, OS file/provider диалоги и NVDA/TalkBack пока не проверены. DOM/keyboard/accessible-name проверки не заменяют скринридер.
- APK подписан debug-ключом; Windows без издательской подписи. Магазины/автообновление не реализованы.
- Работа не названа прототипом, но автоматические проверки не означают доказанную production-надёжность на непроверенных устройствах.

## Обновление и проверка

Перед обновлением экспортируйте полный ZIP. Android обновляйте поверх установленного приложения, не удаляйте его: удаление уничтожает внутренний архив. Если система откажется обновлять APK, не удаляйте старое приложение без внешней резервной копии.

Начните с тестовой семьи: имя → фото/пакет вложений → мать/отец → история → перезапуск → полный ZIP-экспорт/импорт. Дополнительные поля необязательны. В библиотеку можно добавлять файлы без людей. Отмена выбора или ошибка записи не должна очищать карточку. Сохраняйте внешние резервные копии; автоматической синхронизации между родственниками нет.
